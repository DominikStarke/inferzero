Why it matters

inferzero is built by one person on one laptop with an Intel Core Ultra iGPU. Every speed change for the discrete Arc cards (Pro B60, Pro B70, A770, B390) is measured today only by the users who own them, so each change waits for someone's run before it can be checked and released.

Faster development

With the cards here, a change is built, measured and fixed the same day, instead of waiting for a user's run on GitHub.

More accurate

Every change is checked against an exact reference (KL) and bit for bit where it promises the same results. On real hardware those checks run before a release, not after.

Better for everyone

inferzero stays free and open source. Sponsorship pays for the test hardware, not for features behind a paywall.

What sponsorship pays for

  • Test cards: an Arc Pro B60 / B70 and an Arc A770, the cards most users run.
  • A desktop to hold them (two or more cards for the multi-GPU work).
  • The time to measure, tune and check each change on them.
